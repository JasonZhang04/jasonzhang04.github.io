Files whose names start with an underscore, like this one, are never published.
To write a post, copy this file to a new name such as `2026-11-20-my-first-note.md`.
The part after the date becomes the address: /blog/my-first-note/.

`kind` is either `Note`, for thoughts and inspirations, or `Research log`, for early
findings and research experiences. Remove `draft: true`, or set it to false, to publish.

Write the body in Markdown. Headings start at `##`.

## A section

Paragraphs, **bold**, *italics*, [links](https://example.com), lists, quotes,
`inline code` and fenced code blocks all work.
